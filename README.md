# Polimix — Concreto e cimento

Site em HTML, CSS e JavaScript nativos. Abra `index.html` no navegador ou publique esse arquivo e a pasta `assets` em uma hospedagem estática.

Todos os botões e links redirecionam na mesma aba para o WhatsApp **(21) 2888-1609**, com a mensagem **Olá, desejo um atendimento!**. O visitante decide quando enviar a mensagem. A navegação interna, a calculadora e os modais foram substituídos pelo acesso direto ao atendimento, mantendo o design.

Os destinos estão no `index.html`, inclusive para funcionar sem JavaScript. A configuração em `assets/js/config.js` sincroniza os links quando JavaScript está habilitado. Ao alterar número ou saudação, atualize também os endereços `https://wa.me/` no HTML.

Os estilos ficam em `assets/css/style.css` e as imagens em `assets/images`. O site usa Google Fonts com fontes alternativas locais. A licença dos ícones SVG está em `assets/lucide-LICENSE.txt`.
